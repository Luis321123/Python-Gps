## 📖 About

A **GPS / satellite location** project in Python: several scripts fetch
coordinates and plot them on a map, optionally with **Folium**
for interactive output.

## ✨ Features

- Location fetching with and without Folium
- Multiple scripts for different output styles
- Requirements pinned in `requirements.txt`

```bash

pip install -r requirements.txt
python ubicacion3.py
```
